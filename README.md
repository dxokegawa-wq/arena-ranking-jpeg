# 出玉ランキング画像メーカー

メール本文を貼り付けると、パチンコ（発）とスロット（枚）のランキングを読み取り、提供されたExcelの背景を使ってJPEG画像を作成します。ブラウザーだけで動作し、入力した本文は送信・保存されません。

## 使い方

1. GitHub Pages の公開URLを開きます。ローカルで使う場合は、このフォルダーをWebサーバーで配信します（例：`python -m http.server 8000` → `http://localhost:8000/`）。
2. メール本文をそのまま貼り付けます。`2026年9月7日(月)～2026年9月13日(日)` のような期間と、`① 216番台 機種名 9/13 60610発` のような行を読み取ります。
3. 本文の期間を自動取得し、パチンコとスロットの画像を同時に表示します。日付が違う場合だけ「日付が違う場合だけ修正する」を開いて修正します。
4. Web用／サイネージ用のサイズを選び、各「JPEGを保存」から個別に保存するか、「パチンコ・スロットをまとめて保存（ZIP）」から、表示中のサイズのJPEGをまとめて保存します。

各種先頭10件を掲載します。読み取れなかったランキング行は行番号で知らせます。期間が本文になければランキングの日付から仮入力するので、確認・修正してください。

上部の期間の数字は大きな白字にし、Web用スロットでは背景の「月」「日」の位置に合わせて配置します。ランキング欄の台番・機種名・日付・出玉／差枚数は黒い太字を基本に、数字を大きくしながら欄内に収めます。数字は同じ桁数なら各桁の位置が縦にそろうように描画します。機種名は読みやすい太字にし、初めての機種は一行に収めます。機種名の太さと大きさは画面のスライダーで調整でき、設定はブラウザー内に保存されます。二行にしたい場合は、メール本文欄の機種名の途中でEnterを押すと、その位置から二行目になります。改行位置はブラウザー内に記憶され、次回同じ機種を一行で貼り付けても記憶した位置で二行表示します。ブラウザーの保存データを消すと、文字設定と改行の記憶も消えます。行の日付だけ土曜日を青、日曜日と日本の祝日・休日を赤にします。祝日・休日には振替休日なども含みます。年は本文から自動入力し、期間が年をまたぐ場合も判定します。

祝日・休日の出典は[内閣府の公式CSV](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)です。収録範囲は1955〜2027年で、それ以外の年は土日のみ判定して画面に注意を表示します。新しい年の祝日が公表されたら `holidays.js` を更新してください。

## 公開

静的ファイルだけなので、GitHubのリポジトリをPagesで公開できます。リポジトリの Settings → Pages → Build and deployment で `Deploy from a branch`、`main` と `/(root)` を選択します。`assets` の背景画像も公開されるため、公開範囲を確認してください。

## 構成

- `index.html`、`style.css`：操作画面
- `core.js`：メール本文の読み取り
- `holidays.js`：公式の祝日・休日の日付
- `app.js`：プレビュー・JPEG・ZIP作成
- `assets/`：提供されたExcelに含まれるランキング背景（4種類）

サーバー、APIキー、Excel、画像編集ソフト、有料サービスは不要です。
