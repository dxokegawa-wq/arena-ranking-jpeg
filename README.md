# 出玉ランキング画像メーカー

メール本文を貼り付けると、パチンコ（発）とスロット（枚）のランキングを読み取り、提供されたExcelの背景を使ってJPEG画像を作成します。ブラウザーだけで動作し、入力した本文は送信・保存されません。

## 使い方

1. GitHub Pages の公開URLを開きます。ローカルで使う場合は、このフォルダーをWebサーバーで配信します（例：`python -m http.server 8000` → `http://localhost:8000/`）。
2. メール本文をそのまま貼り付けます。`2026年9月7日(月)～2026年9月13日(日)` のような期間と、`① 216番台 機種名 9/13 60610発` のような行を読み取ります。
3. 日付を確認し、パチンコ／スロットとWeb用／サイネージ用を選びます。
4. 「表示中のJPEGを保存」を押します。両種・両サイズを使う場合は「読み取った画像をまとめて保存」でJPEG入りのZIPを保存できます。

各種先頭10件を掲載します。読み取れなかったランキング行は行番号で知らせます。期間が本文になければランキングの日付から仮入力するので、確認・修正してください。

## 公開

静的ファイルだけなので、GitHubのリポジトリをPagesで公開できます。リポジトリの Settings → Pages → Build and deployment で `Deploy from a branch`、`main` と `/(root)` を選択します。`assets` の背景画像も公開されるため、公開範囲を確認してください。

## 構成

- `index.html`、`style.css`：操作画面
- `core.js`：メール本文の読み取り
- `app.js`：プレビュー・JPEG・ZIP作成
- `assets/`：提供されたExcelに含まれるランキング背景（4種類）

サーバー、APIキー、Excel、画像編集ソフト、有料サービスは不要です。
